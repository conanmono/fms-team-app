## 1. Problem
ผู้เยี่ยมชมยังไม่มีทางดูรายการคอร์สทั้งหมดของแพลตฟอร์ม และเมื่อคอร์สมีหลายหมวดหลายระดับ ผู้เยี่ยมชมต้องหาคอร์สที่ตรงกับความสนใจและพื้นฐานของตัวเองได้เร็ว ถ้าหาไม่เจอก็จะไม่ซื้อ
หน้ารวมคอร์สเป็นทางเข้าหลักก่อนไปดูรายละเอียด ใส่ตะกร้า และชำระเงิน จึงต้องทำเป็นฟีเจอร์แรก

## 2. Goals / Out of scope
**Actor:** ผู้เยี่ยมชม (ไม่ต้องเข้าสู่ระบบ)

**Goals**
- ผู้เยี่ยมชมเห็นรายการคอร์สที่เปิดขายอยู่
- ค้นหาคอร์สจากชื่อ กรองตามหมวดและระดับ และเรียงลำดับได้ 4 แบบ: ใหม่ล่าสุด, ราคาน้อยไปมาก, ราคามากไปน้อย, คะแนนรีวิว
- เงื่อนไขที่เลือกอยู่ในลิงก์ของหน้า แชร์หรือกดย้อนกลับแล้วได้ผลเหมือนเดิม
- การ์ดคอร์สแต่ละใบให้ข้อมูลพอตัดสินใจว่าจะกดเข้าไปดูต่อหรือไม่
- เงื่อนไขที่ผิดรูปแบบไม่ทำให้หน้าพัง

**Out of scope**
- หน้ารายละเอียดคอร์ส (การ์ดลิงก์ไปหน้านั้นได้ แต่ตัวหน้าเป็นอีกฟีเจอร์)
- ปุ่มเพิ่มลงตะกร้าบนการ์ด
- แบ่งหน้า (pagination) / โหลดเพิ่ม
- ค้นหาจากคำอธิบายหรือเนื้อหาบทเรียน, ค้นหาแบบคลาดเคลื่อน (fuzzy), แนะนำคำค้น
- หน้าแรก, navbar และ layout ส่วนหน้าร้าน
- คอร์สฟรีจาก API ภายนอก (US-11) และการจัดการคอร์สหลังบ้าน (US-15)
- E2E test (traceability matrix ของ R2 ไม่มี E2E)

## 4. Constraints
- เงินเก็บเป็นจำนวนเต็มหน่วยสตางค์ และแสดงผลด้วย `formatTHB` เท่านั้น
- ไม่แก้ `prisma/schema.prisma` ฟีเจอร์นี้อ่านข้อมูลอย่างเดียว
- ค่าระดับและข้อความภาษาไทยของระดับใช้ชุดเดียวกับที่ระบบมีอยู่ (เริ่มต้น / กลาง / สูง)
- ฟีเจอร์นี้ไม่มี business error ค่าที่ผิดรูปแบบทุกกรณีถูกปรับเป็นค่าที่ใช้ได้ ผู้เยี่ยมชมไม่เห็นข้อความ error
- ไม่ต้องเข้าสู่ระบบ และไม่แสดงข้อมูลของผู้ใช้คนใด

## 5. Acceptance Criteria
AC ทุกข้อเขียนตามข้อสรุปในข้อ 6 แล้ว ถ้าจะเปลี่ยนข้อสรุปใดต้องแก้ AC ที่เกี่ยวข้องผ่าน PR ของ spec ก่อนแก้โค้ด

**แสดงผลเริ่มต้น (FR-01)**
- AC1: **Given** มีคอร์สที่เปิดขายหลายคอร์ส **When** ผู้เยี่ยมชมเปิดหน้ารวมคอร์สโดยไม่ได้เลือกเงื่อนไขใด **Then** เห็นคอร์สที่เปิดขายทั้งหมด เรียงจากคอร์สที่เพิ่มล่าสุดก่อน
- AC2: **Given** มีคอร์สที่ยังไม่เปิดขาย (ปิดการเผยแพร่) **When** ผู้เยี่ยมชมดูหน้ารวมคอร์สด้วยเงื่อนไขใดก็ตาม รวมถึงค้นด้วยคำที่ตรงกับชื่อคอร์สนั้น **Then** ไม่เห็นคอร์สนั้น

**ค้นหา (FR-02)**
- AC3: **Given** มีคอร์สชื่อ "Unit Testing ด้วย Vitest" และ "E2E Testing ด้วย Playwright" **When** ค้นด้วยคำว่า "test" **Then** เห็นทั้งสองคอร์ส (ไม่สนตัวพิมพ์เล็ก/ใหญ่ของอักษรอังกฤษ) และไม่เห็นคอร์สที่ชื่อไม่มีคำนี้
- AC4: **Given** ผู้เยี่ยมชมพิมพ์คำค้นที่มีช่องว่างหน้า/หลัง เช่น "␣␣react␣␣" **When** ค้นหา **Then** ระบบค้นด้วย "react"
- AC5: **Given** คำค้นว่าง หรือมีแต่ช่องว่าง **When** ค้นหา **Then** ถือว่าไม่ได้ค้นหา และเห็นคอร์สตามเงื่อนไขอื่นตามปกติ
- AC6: **Given** คำค้นที่ตัดช่องว่างหน้าหลังแล้วยาว 101 ตัวอักษร **When** ค้นหา **Then** ระบบใช้เฉพาะ 100 ตัวอักษรแรก และไม่แสดง error (คำค้นยาว 100 ตัวอักษรใช้ได้ครบ)

**กรอง (FR-03)**
- AC7: **Given** มีคอร์สหลายหมวด **When** เลือกหมวดหนึ่ง **Then** เห็นเฉพาะคอร์สในหมวดนั้น และถ้าลิงก์ระบุหมวดที่ไม่มีอยู่จริง ผลลัพธ์ว่างตาม AC20
- AC8: **Given** มีคอร์สระดับเริ่มต้น กลาง และสูง **When** เลือกระดับ "เริ่มต้น" **Then** เห็นเฉพาะคอร์สระดับเริ่มต้น
- AC9: **Given** ลิงก์ระบุระดับที่ระบบไม่รู้จัก (เช่น "EXPERT") **When** เปิดหน้า **Then** ถือว่าไม่ได้กรองระดับ เห็นคอร์สทุกระดับ และหน้าไม่แสดง error
- AC10: **Given** ผู้เยี่ยมชมใส่ทั้งคำค้น หมวด และระดับ **When** ดูผลลัพธ์ **Then** เห็นเฉพาะคอร์สที่ตรงทุกเงื่อนไขพร้อมกัน

**เรียงลำดับ (FR-04)**
- AC11: **Given** คอร์สราคา 2,990 / 990 / 1,890 บาท **When** เลือกเรียง "ราคาน้อยไปมาก" **Then** ลำดับคือ 990, 1,890, 2,990 และเมื่อเลือก "ราคามากไปน้อย" ได้ลำดับกลับกัน
- AC12: **Given** มีคอร์สที่มีรีวิวและคอร์สที่ยังไม่มีรีวิว **When** เลือกเรียง "คะแนนรีวิว" **Then** คอร์สคะแนนเฉลี่ยสูงกว่าอยู่ก่อน และคอร์สที่ยังไม่มีรีวิวอยู่ท้ายสุดเสมอ
- AC13: **Given** สองคอร์สมีคะแนนเฉลี่ยเท่ากัน 4.5 แต่มีรีวิว 2 และ 10 รายการ **When** เรียง "คะแนนรีวิว" **Then** คอร์สที่มีรีวิว 10 รายการอยู่ก่อน
- AC14: **Given** ลิงก์ระบุการเรียงที่ระบบไม่รู้จัก (เช่น "cheap") **When** เปิดหน้า **Then** เรียงแบบใหม่ล่าสุด และหน้าไม่แสดง error

**ลิงก์และค่าที่ผิดรูปแบบ (FR-05)**
- AC15: **Given** ลิงก์มีเงื่อนไขเดียวกันซ้ำหลายค่า (เช่น คำค้น "a" และ "b") **When** เปิดหน้า **Then** ระบบใช้ค่าแรก ("a")
- AC16: **Given** ผู้เยี่ยมชมค้น "react" และเรียงแบบใหม่ล่าสุด (ค่าเริ่มต้น) **When** ระบบสร้างลิงก์ของหน้าเอง (เช่น ลิงก์ล้างเงื่อนไข หรือลิงก์ที่หน้าอื่นชี้มา) **Then** ลิงก์มีเฉพาะคำค้น ไม่ใส่ค่าที่เป็นค่าเริ่มต้น (`?q=react`)
- AC21: **Given** ลิงก์ระบุคำค้น หมวด ระดับ และการเรียงที่ถูกต้อง **When** เปิดลิงก์นั้นโดยตรง กดย้อนกลับมา หรือ refresh **Then** ฟอร์มแสดงค่าที่เลือกตรงกับลิงก์ และผลลัพธ์ตรงกับเงื่อนไขนั้น

**การ์ดคอร์ส (FR-06)**
- AC17: **Given** คอร์สมี 2 บทเรียนยาว 10 และ 15 นาที และมีรีวิวคะแนน 5, 4, 4 **When** แสดงบนหน้ารวมคอร์ส **Then** การ์ดแสดง: รูปคอร์ส, ชื่อคอร์ส, ชื่อหมวด, ระดับเป็นภาษาไทย, ราคาในรูปแบบเงินบาท (เช่น ฿1,290.00), จำนวนบทเรียน 2 บท, ความยาวรวม 25 นาที, คะแนนเฉลี่ย 4.3 (ทศนิยม 1 ตำแหน่ง) และจำนวนรีวิว 3 รายการ และกดการ์ดแล้วไปหน้ารายละเอียดของคอร์สนั้น
- AC18: **Given** คอร์สยังไม่มีรีวิว **When** แสดงการ์ด **Then** แสดงว่ายังไม่มีรีวิว แทนคะแนน
- AC19: **Given** ข้อมูลระดับของคอร์สในระบบเสีย (ไม่ใช่ เริ่มต้น/กลาง/สูง) **When** แสดงหน้ารวมคอร์ส **Then** การ์ดแสดงระดับ "เริ่มต้น" และหน้าไม่พัง

**ไม่พบผลลัพธ์ (FR-07)**
- AC20: **Given** ไม่มีคอร์สที่ตรงเงื่อนไข **When** ดูผลลัพธ์ **Then** เห็นข้อความว่าไม่พบคอร์ส พร้อมทางล้างเงื่อนไขทั้งหมด
